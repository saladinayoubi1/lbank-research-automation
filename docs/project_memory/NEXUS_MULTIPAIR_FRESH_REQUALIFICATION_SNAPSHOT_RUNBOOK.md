# Runbook guardrails

The fresh runtime snapshot is acquired only after historical Discovery has completed, so the 15-minute cell is not aged by the historical archive acquisition and Discovery stage. A physical consumer must reject a transported runtime snapshot that is older than the fixed transport budget or whose latest closed candle is outside the canonical freshness window.

Do not substitute another exchange, proxy Bybit, use private API credentials, reuse the historical Discovery archive as fresh evidence, or persist the transported snapshot as a GitHub runtime database. A failed freshness or provenance check is a failed requalification, not permission to relax the gate.
