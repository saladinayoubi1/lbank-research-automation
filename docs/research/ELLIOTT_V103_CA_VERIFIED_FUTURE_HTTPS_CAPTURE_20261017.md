## Transport and retained raw evidence

- Python standard library `http.client.HTTPSConnection` opens a **direct** connection to fixed host/port, `ssl.create_default_context` checks the OS CA trust chain + target hostname; TLS minimum 1.2, without following redirects or using system HTTP-proxy environment variables. Only HTTP 200, `application/json`, identity content encoding, no nonzero `Age`, and a bounded raw byte response are accepted.
- Read the remote TLS leaf certificate's **DER bytes** from the verified socket and retain their SHA256 and negotiated TLS protocol; retain immutable HTTP response body *bytes* and per-page receipt. Keep request path/query, host, method, status, whitelisted HTTP date/content headers, captured UTC start/end instants, monotonic elapsed duration, raw SHA256, and byte length. Do **not** store secrets, broad ambient headers, bearer tokens, authentication objects, or private conversation data.
- The collector immediately passes each raw response to V102's strict reverse-sorted physical 1m OHLC validator before saving; bytes + receipt are stored in per-page no-overwrite files. Two files per page, **84 total**: `BTCUSDT-00.raw.json`, `BTCUSDT-00.receipt.json`, and analogous locked pages. Missing sidecar or interrupted raw write is **invalid**, never silently repaired.
- After all 42 pages exist, a separately callable `--mode audit --capture-dir PATH` recomputes every original byte hash, checks all TLS/HTTP fields against the frozen request identity, rejects missing/extra files, verifies receipt chronology and full V102 40,320-candle contiguous OHLC/volume timeline, and returns a research-only integrity receipt. No Elliott wave classifier, entry/exits, P/L or Demo adapter are invoked.
- **Provenance limitation:** The actual public Bybit V5 JSON is not cryptographically signed by the exchange. A TLS-verified direct connection offers trusted transport identification under the Windows root store during collection, but a locally written receipt and leaf-certificate hash are **self-reported**, not independent tamper-proof origin attestation. Offline SHA checks prove internal preservation, **not** that Bybit authored or signed a given file; require an independent collection audit before any later scientific market-data claim. False TLS metadata inserted into an offline envelope cannot be detected beyond schema validation without external trustworthy recording.
