## Concrete defect

The separately reviewed DSL intake describes context and entry. Its simulator
supplies a fixed range-based stop, target, timeout, cash model and sizing. A
signal-only permit could therefore be labeled approved for research without a
reviewed complete system saying that these were its intended exits and risks.
An Elliott structural invalidation could be substituted by a range stop in a
purported full-system study. The standalone CLI also failed to establish its
repository import path when run from an unrelated working directory.

The existing intake now consumes an exact complete-system specification before
market I/O. A signal-only permit returns
`REVIEW_REQUIRED_COMPLETE_SYSTEM_SPECIFICATION`. The same existing allowlist
can bind the complete specification path/SHA and actual execution-contract
digest; no separate approval registry or parallel engine is introduced. Its
production list remains empty. The existing CLI establishes its own repository
import path and executes the same source-verified evaluator.

## Explicit executable contract

`execution_contract()` exposes the current simulator semantics from its actual
cash/risk/cost constants. It makes the following scope explicit: Bybit Spot,
BTC/ETH, one shared 500-USDT cash book, completed 15m decisions with completed
1h/4h context, next-open entry, existing collision priority, one portfolio
position, cost-aware quantity, gap/stop/target precedence, timeout, inspected
60/20/20 partitions and separate conservative/stress costs. Its range proxy is
a shifted mean high-low range, not Wilder ATR or an Elliott structural stop.
The research diagnostic has no portfolio drawdown kill; the contract says so.

The complete-system schema requires:

- exact candidate path, raw SHA and factory contract digest;
- source-note paths, hashes and HTTPS references;
- explicit context, entry, exit, sizing and no-trade rule mappings;
- a distinction between source-described rules and research extensions;
- an exact supported execution contract and six pinned implementation files;
- one frozen study window and no post-hoc tournament;
- research-only authority with Paper/Live/automatic promotion false.

The six hashes must match the actually imported executor as well as the
reviewed files. Rehashing a different caller-provided source tree cannot
impersonate the running code.

Changed source notes, reviewed bytes, executable source or unsupported
exits/risk fail closed. A changed study window is refused before market input
lookup. Candidate identity is checked again before signal execution, and the
complete evidence binding is checked again after replay. Successful research
output retains its complete-system digest and actual execution contract.

These are bindings to reviewed artifacts, not cryptographic proof of an
outside review, publisher authenticity or global novelty. A source note is
explicitly a bounded research paraphrase, never relabeled as raw provider bytes.
