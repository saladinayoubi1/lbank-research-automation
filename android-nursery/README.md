# Nursery Daily Android

اپ آفلاین ثبت روزانه نرسری و قرنطینه بر پایه فایل اکسل کاربر.

- داده‌های تاریخی داخل خود اپ قرار می‌گیرند.
- داده‌های جدید در LocalStorage خود WebView ذخیره می‌شوند.
- CSV و JSON با Android Storage Access Framework ذخیره می‌شوند.
- بازیابی JSON از فایل‌منیجر Android پشتیبانی می‌شود.
- اپ برای کار روزانه به اینترنت نیاز ندارد.

نسخه فعلی: 1.0.0
